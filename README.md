# Jazz Chord Flash Quiz (PWA)

スマホ向け4択クイズです。

## 収録モード
- 3度
- 5度
- 7度
- コード構成音
- アボイドノート
- 苦手問題だけ復習

## 学習記録
回答数・正答率・間違い傾向をブラウザ内（localStorage）に保存します。

## アボイドノートについて
「絶対に弾いてはいけない音」ではなく、コード上で長く保持すると響きを濁しやすい音として扱います。
設定で「実用ベーシック」と「Nettles/Graf系」を切り替えられます。
理論上、流派・文脈によって扱いが異なるため、問題文には必ず使用スケールを表示します。

## PWAとして使う
PWAは HTTPS で配信する必要があります（localhostを除く）。
GitHub Pages / Netlify / Cloudflare Pages など静的ホスティングに、このフォルダの中身をそのまま配置してください。
iPhoneではSafariで開き、共有 →「ホーム画面に追加」でアプリ風に使えます。
一度読み込めばService Workerによりオフラインでも動作します。
